# growi-plugin-print-layout

GROWI のページを、レイアウトを調整してから PDF に印刷するためのプラグインです。

ブラウザ標準の印刷では、改ページの位置や画像の大きさを調整できません。このプラグインは全画面の調整画面を開き、ページを用紙単位に分けてプレビューします。そのプレビュー上で改ページ・画像の大きさ・2段組の左右の比率・余白・用紙の向きを調整し、見たままの状態で PDF に印刷できます。画面では横スクロールになる幅の広い表やコードブロックも、用紙の幅に収まるよう自動で折り返し・縮小します。調整内容は GROWI の子ページに保存されるため、本文を更新したあとも、チームの誰でも同じ調整で印刷し直せます。

## 依存

- GROWI 8.x（GROWI 8.0.4 で動作確認済み）
- [`growi-plugin-extension-hub`](https://gitea.drupal-yattemiyo.com/growi-plugins/growi-plugin-extension-hub) がインストールされ、有効になっていること
  - 調整画面は hub のメニューから開きます。hub がないとメニューが表示されません。
- ブラウザ: Chrome / Edge

## インストール

GROWI 管理画面 → プラグイン → 新規登録で、このリポジトリの Gitea の URL を指定します。

```
https://gitea.drupal-yattemiyo.com/growi-plugins/growi-plugin-print-layout
```

登録したら、ページを再読み込みしてください。hub のメニューに「印刷レイアウト」が表示されます。

## 使い方

1. 印刷したいページを開き、hub のメニューから **印刷レイアウト** を選びます。全画面の調整画面が開きます。
   - 左側: 設定パネル
   - 中央: 用紙ごとのプレビュー
2. 左パネルで、用紙と余白を設定します。
   - **用紙**: A4 / A3 / B5（JIS B5、182×257mm）。初期値は A4
   - **向き**: 縦 / 横
   - **余白 (mm)**: 上・下・左・右。0〜50mm の範囲で指定します。初期値は上下 15mm、左右 20mm
3. プレビュー上で、改ページを調整します。
   - **追加**: ブロック（見出し・段落・表など）の境目にマウスを合わせると「＋ ここで改ページ」が出ます。クリックすると追加されます。
   - **移動**: 手動の改ページは赤い点線で表示されます。点線をドラッグして別の境目に落とすと移動します。
   - **削除**: 点線の右端にある「×」で削除します。
   - 自動で入った改ページの位置は、薄い線で表示されます。
4. 画像をクリックすると、右下にハンドルが出ます。ハンドルをドラッグすると、縦横比を保ったまま拡大・縮小できます。drawio の図も同じです。
   - 大きさは本文幅に対する %（5〜100%）で記録されます。
   - 「元のサイズに戻す」で、その画像の調整を外せます。
5. 2段組（左右に並んだ段組）をクリックすると、左右の段の境目に仕切りが出ます。仕切りを左右にドラッグすると、左段の比率を 5% 刻み（10〜90%）で変えられます。離すとすぐにページ分割をやり直します。
   - 対象は、横並びの flex（`display: flex`）で、子要素がちょうど 2 つの要素です。入れ子の段組も対象です。インラインの `style="display:flex"` でも、GROWI のカスタム CSS でクラスに定義した flex（例: `.f2_container{display:flex}` と `<div class="f2_container"><div class="f2_item">…</div><div class="f2_item">…</div></div>`）でも使えます。
   - 「元の比率に戻す」で、その段組の調整を外せます。Escape キーか段組の外側のクリックで選択を解除します。
   - 変わるのはプレビューと印刷だけです。ページの本文や CSS は変わりません。
6. 表とコードブロックは、用紙の幅に収まるよう自動で調整されます（右端が切れません）。
   - まず折り返します。表はセルの中の文章を、コードは長い行を、言葉の切れ目で折り返します。単語の途中では切りません（日本語は 1 文字単位で折り返します）。表の中のリンクとインラインのコードだけは、途中でも折り返します。
   - それでも幅に入らないもの（列の多い表、長い単語や URL・トークンを含むコード、幅が固定されたセルや画像を含む表など）は、表・コードごと縮小します。
   - 段組の中やリストの中の表・コードも対象です。ページをまたいで分割された表・コードは、どのページも同じ倍率になります。
   - プレビューの各表・コードブロックの右上に、今の状態を示すバッジが出ます（印刷には出ません）。例: 「自動」「自動・縮小 78%」「縮小のみ 64%」「倍率 80%」
   - バッジをクリックすると、次の 3 つから選べます。選ぶとすぐにページ分割をやり直します。
     - **自動**: 折り返してから、必要なら縮小します（初期値）。
     - **縮小のみ**: 折り返さず、元の形のまま幅に収まる倍率まで縮小します。表のセルやコードの行を折り返したくないときに使います。
     - **倍率を指定**: 50〜100% を 5% 刻みで選びます（折り返しあり）。選ぶとメニューが開いたままになり、続けて倍率を選べます。
   - 次の場合は、左パネルに「幅合わせの警告: N 件」として一覧で表示します。表やコードは、本文での順番で「表 1」「コード 2」のように示します。
     - 自動・縮小のみで 60% 未満まで縮小したとき: 「表 4: 縮小 52%（文字が小さくなります）」
     - 倍率を指定して、幅に収まらないとき: 「表 4: 倍率 100% では幅に収まりません（右端が切れます）」
     - 自動・縮小のみでも幅に収められなかったとき: 「表 4: 幅に収まりません（右端が切れます）」
     - 警告の出ている表・コードのバッジは黄色で表示します。
7. 見出しの単位で、印刷したくない部分を隠せます。
   - **隠す**: プレビューで見出しにマウスを合わせると、見出しの左に開いた目のボタンが出ます（Tab キーでボタンに移ったときも出ます）。押すと、その見出しの範囲が印刷から外れます。
   - **範囲**: その見出しから、次に同じか上の階層の見出しが出る手前までです。例: `## 2章` を隠すと、次の `## 3章` か `# 第2部` の手前まで隠れます。該当する見出しがなければ本文の最後までです。
   - 隠した部分は印刷に出ません。後ろの内容は詰めて、前のページに繰り上がります。プレビューのページ分けも印刷と同じです。
   - **灰色の線**: 隠した場所には灰色の点線と、閉じた目のアイコン・見出しの文字が出ます（印刷には出ません）。アイコンを押すと元に戻ります。
   - **見出し一覧**: 左パネルの「見出し」に本文の見出しが並び、目のボタンで隠す・戻すを切り替えられます。自分で隠した見出しは取り消し線で、外側の見出しに含まれて隠れている見出しは「（上の見出しで非表示）」と表示します。
   - 隠した範囲の中の見出しも個別に隠せます。外側を戻しても、個別に隠した内側は隠れたままです。
   - 隠した範囲の中の調整（改ページ・画像の幅・2段組の比率・幅合わせ）は消えません。隠している間だけ効かず、戻すとそのまま効きます。
   - すべてを隠すと、プレビューは空のページ 1 枚になり、「PDF に印刷」が押せなくなって「印刷する内容がありません」と出ます。
   - 隠す設定は保存されます（下の「設定の保存先と閲覧権限」）。
8. **自動に戻す** を押すと、このページの調整がすべて初期状態に戻ります。保存するまでは、保存済みの設定は変わりません。
9. **保存** で調整内容を保存します。自動保存はしません。
10. **PDF に印刷** で、ブラウザの印刷ダイアログが開きます。送信先で「PDF に保存」を選び、次のように設定してください（初回は画面にも案内が出ます）。
   - **余白**: なし
   - **背景のグラフィック**: オン（コードブロックの背景色などを残すため）
   - 隠す設定のうち本文に見つからないものがあるときは、印刷の前に確認が出ます（例:「隠す設定のうち 1 件が本文に見つかりません。隠したつもりの内容が印刷される可能性があります。」と、見つからない見出しの文字。10 件を超える分は「ほか N 件」）。保存された隠す設定の一部や設定ページ全体を読み取れなかったときも、同じように確認が出ます。OK で印刷し、キャンセルでやめます。ゲストにも同じ確認が出ます。すべて読み取れて一致しているときは出ません。
11. **閉じる** で調整画面を閉じます。編集モードに切り替えたときや、別のページに移動したときも自動で閉じます。

## 設定の保存先と閲覧権限

- 調整内容は子ページ `<元ページのパス>/_print-layout` に保存されます。ルートページ `/` の場合は `/_print-layout` です。
  - ページツリーに表示され、GROWI のページ履歴が残ります。
  - 本文は説明文 1 行と JSON のコードブロックです。手で編集しないでください。
  - 保存される内容: 用紙・向き・余白（`page`）、手動の改ページ（`breaks`）、画像の幅 %（`images`）、2段組の左段の比率 %（`columns`。10〜90 の整数）、表・コードブロックの幅合わせ（`fits`。「縮小のみ」か「倍率を指定」にしたものだけ。「自動」は保存しません）、隠した見出し（`hidden`。見出しの文字の先頭 100 文字を表示用に持ちます）。改ページ・画像・2段組・幅合わせ・隠した見出しは、それぞれ対象を特定するためのアンカーと一緒に記録します。隠した見出しのアンカーには、上の階層の見出しの並びも含めます。
  - 内容が壊れていても調整画面は開きます。その場合は「保存された設定を読み取れませんでした」と表示し、初期状態で開きます。
- 子ページは、**元ページと同じ閲覧権限**で作成されます（作成時に元ページの権限とグループを明示して渡します）。見出しの文字などが、子ページを通して本来見えない人に見えないようにするためです。
  - GROWI が同じ権限での作成を受け付けなかった場合（所属していないグループのページなど）や、既存の子ページの権限が元ページと違う場合は、保存せずに「元ページと同じ閲覧権限で保存できません（保存先: …）」と表示します。子ページの権限を GROWI の画面で確認・修正してください。
  - 保存したあとの確認で権限が違っていた場合は、「元ページと同じ閲覧権限で保存できませんでした。子ページ … の権限を確認してください」と表示します。
  - 元ページの権限があとから変わり、子ページの閲覧範囲の方が広くなった場合は、調整画面を開いたときに「この設定ページの閲覧範囲が元ページより広くなっています」と警告します。自動では直しません。
- 保存できるのはログイン中のユーザーです。ゲストは保存済みの調整でプレビューと印刷ができますが、「保存」ボタンは無効です。
- ほかの人が先に保存していた場合は、「ほかの人が更新しました。再読み込みしますか？」と表示します。黙って上書きはしません。
- 調整は、ブロック・画像・2段組・表・コードブロックの内容（見出しの文字など）をもとに対応づけて記録します。本文を更新したあと、対応が取れた調整はそのまま適用されます。
  - 前回の保存後に本文が更新されていると、「前回の調整後に本文が更新されています」と表示します。
  - 対応が取れなかった調整は、左パネルの「適用できなかった調整: N 件」に一覧で表示されます。そこから削除できます。
  - 隠す設定は「非表示: 見出しの文字」と表示します。見出しの文字や、その上の階層の見出しの文字を変えると対応が取れなくなります（章ごとに同じ名前の見出しがあっても、別の章の見出しに移ることはありません）。対応が取れない隠す設定があると、印刷の前に確認が出ます。

## 制限事項

- 見出しを次の段落と同じページに送る処理（keep-with-next）はありません。見出しだけがページの最後に残った場合は、手動で改ページを入れてください。
- 1 ページに入らないブロックは、次のように扱います。
  - 表: 行単位で分割し、各ページで見出し行を繰り返します。
  - コードブロック: 行単位で分割します。
  - 画像・drawio: ページに収まるよう縮小します。
  - 囲み（`div` など）: 子要素の境目で分割します。中で2段組が折り返して積まれている場合は、段の行単位で分割するので、左右の対が途中で切れることはありません。入れ子の囲みは、さらにその中の子要素の境目で分割します。
  - 子要素が 2 つだけの段組: 1 行しかないので分割せず、ページに収まるよう縮小します。
  - 長い段落や段組のまとまり: 分割せず、ページ内に収まるよう縮小します。縮小したブロックは、プレビューでオレンジの点線で囲みます（印刷には出ません）。文字が小さくなりすぎる場合は、改ページや画像の大きさで調整してください。
- 表やコード、囲み（`div` など）の途中には、手動の改ページを入れられません。
- 隠せるのは、本文の直下にある見出し（`h1`〜`h6`）だけです。段組・リスト・引用の中の見出しは対象外で、前にある見出しの範囲に含まれます。最初の見出しより前の内容は隠せません。
- 表やコードブロックの外にある長い URL を含む段は、指定した比率より広くなることがあります（段の中の表・コードは、段の幅に合わせて縮小します）。
- 列の多い表や、長いトークンを含むコードは、自動では単語の途中で切らずに縮小するため、文字が小さくなることがあります（60% 未満は警告に出ます）。段組の中では、段の幅に合わせてさらに小さくなります。横向きにするか、余白を狭くすると大きく印刷できます。
- 調整画面を開いている間は Ctrl+P / Cmd+P を「PDF に印刷」と同じ動作にします（隠す設定の確認も出ます）。ブラウザのメニューから印刷した場合は、この確認を通りません。
- 対応ブラウザは Chrome / Edge だけです。
- プラグイン自身は、同じ GROWI サーバーの API（`/_api/v3/*`）以外とは通信しません。ただし GROWI 本体の drawio ビューアは、GROWI の設定で変えていない限り `embed.diagrams.net` から読み込まれます。これはプラグインではなく、GROWI 本体の通信です。

## 開発

```bash
npm install
npm test        # vitest run
npm run typecheck  # tsc（本体とテスト）
npm run build   # tsc && vite build
```

`dist/` はリポジトリにコミットします（GROWI がビルド済みのファイルを直接読み込むため）。

### 検証環境での確認

検証用の GROWI（WSL2 + Docker）の作り方は `docs/test-env.md` にあります。`scripts/e2e/e2e-full.mjs` は、その環境で通しの確認を 21 項目自動で行い、PASS / FAIL の表を出します。サンプルデータ（`scripts/test-env/setup-sample-data.py` が作る、カスタム CSS でクラスに定義した 2段組、幅の広い表と長い行のコードブロックを含むもの、見出しを隠す確認用の `/print-layout-sample-hide`）が前提です。

```bash
cd scripts/e2e
npm install
node e2e-full.mjs chromium   # Edge で確認する場合は msedge
```

- 環境変数 `E2E_SHOTS` にフォルダーを指定すると、見出しを隠す確認のスクリーンショットを保存します。`E2E_ONLY=hide` で、見出しを隠す確認（17〜21）だけを実行します。

- スクリプトは、確認用のユーザー `viewer2` を一度だけ作成します。このユーザーはそのまま残ります。
- それ以外の変更は、終了時に元に戻します。
  - サンプルページの本文（`/print-layout-sample`、`/print-layout-sample-hide`）
  - ゲストの閲覧設定
  - 作成した `_print-layout` 子ページ（削除します）
  - 実行前からあった `_print-layout` 子ページ: 開始時にいったん削除し（本文は出力先のフォルダーにも保存します）、終了時に同じ本文・閲覧権限で作り直します。新しいページとして作るため、ページの履歴は引き継がれません。
- Chrome の印刷ダイアログ（「余白: なし」「背景のグラフィック: オン」での見た目）は自動では確認できません。PDF はヘッドレスブラウザの PDF 出力（`@page` のサイズを使用）で確認しています。印刷ダイアログでの確認は、人の手で行ってください。
